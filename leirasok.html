TLP telepítése

A TLP automatikusan optimálja a fogyasztást:

Telepítése:

sudo apt update && sudo apt install tlp tlp-rdw

Engedélyezés és azonnali indítás:

sudo systemctl enable --now tlp

Működés ellenőrzése:

sudo tlp-stat -s
